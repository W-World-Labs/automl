# Historical source

`AutoML/` preserves the original v1 implementation and paper/reproduction source
for review. The current runnable platform is the root `crates/` and `web/`
workspace. Operator deployment and private CI assets are excluded.

The original research model, training and evaluation implementations remain;
unreviewed manuscripts, compiled papers, generated images, datasets and model weights do not.
Read the repository's source provenance and license notices before copying or
running an example. Historical manifests and paper claims are not evidence of
current runtime state, input redistribution rights or reproduced results.
